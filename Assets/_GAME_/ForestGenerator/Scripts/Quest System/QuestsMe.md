# PROCEDURAL QUEST GENERATOR

## QUEST STRUCTURE

- Quest Components

  > - Objectives - the task that the player must complete.
  > - Reward - The incentive for completing the quest.
  > - Location - The area where the quest takes place.
  > - NPCs - Characters involved in the quest.
  > - Storyline // optional

- Quest Types

  > - Fetch quests
  > - Kill quests
  > - Escord quests
  > - puzzle quests
  > - Exploration quests

- Create a Quest Template

  > - Data Structure: Define a data structure to represent a quest, including fields for each component.
  > - Variables: Allow for customization by using varaibales that can be randomly generator or determined based on other factors.

- Generate Quest Elements

  > - Randomization: Use random number generators to create VARIATIONS in quest elements such as:
  >   > - Locations: Select random locations from a pool of possibilities.
  >   > - NPCs: Assign random NPCs to quest roles
  >   > - Objectives: Generate random objectives based on QUEST TYPE and LOCATION.
  >   > - Rewards: Determine random rewards based on quest difficulty and player level.

  > - Constraints: Ensure that generated quests are FEASIBLE and make sense within the game world by imposing constraints, such as:
  >   > - Level requirements: Ensure quests are appropriate for the player's level.
  >   > - Logical Connections: Ensure quests are logically connected to the game's storyline and other quests.
